01 / BROWSER

Web Serial is available in current desktop versions of Chrome and Microsoft Edge. This tool needs a secure connection or localhost.

02 / MANIFEST

Bring your own firmware

This page does not host or select firmware. Check the manifest publisher, board compatibility, and firmware contents before installing.

03 / CONNECTION

Keep the board connected

Close other serial tools first. Do not unplug the device or close this page while installation is in progress.
